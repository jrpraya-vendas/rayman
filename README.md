# RAYMAN

Assistente de IA pessoal, 100% local (base: OpenJarvis, de Stanford), com persona em portugues do Brasil, conversa por voz, HUD visual, notas do Obsidian, busca web em tempo real e acesso remoto via Telegram (celular, computador e Apple Watch).

## Instalar (macOS, um comando)

Abra o Terminal e rode:

curl -fsSL https://raw.githubusercontent.com/jrpraya-vendas/rayman/main/install_rayman.sh | bash

O instalador cuida de tudo: uv, Ollama, modelo local qwen3.5:2b (~2,7 GB), voz Kokoro pt-BR, persona RAYMAN e os comandos abaixo.

## Comandos

- rayman — chat por texto
- - rayman-voz — conversa por voz (diga "desligar" pra sair)
  - - rayman-show — bata palma 2x: HUD + voz
    - - rayman-hud — tela de status ao vivo
      - - rayman-obsidian — pergunta usando suas notas
        - - rayman-web — busca na internet em tempo real
          - - rayman-telegram — RAYMAN no Telegram, de qualquer lugar
            - - rayman doctor — diagnostico
             
              - Guia completo: veja LEIA-ME_RAYMAN.md neste repositorio.
             
              - Base: https://github.com/open-jarvis/OpenJarvis (Apache 2.0)a# RAYMAN
